## 1. 코드 설명
본 과제에서는 5채널 전완 및 상완 sEMG 신호를 기반으로 사용자의 4가지 손동작과 2가지 팔꿈치 각도(총 8개 클래스)를 동시에 분류하는 머신러닝 파이프라인을 구현하였다.

* **사용한 데이터 및 전처리 방법 :**
  * 1000Hz로 샘플링된 5채널 sEMG 원본 신호를 활용하였다.
  * 60Hz 노치 필터로 전원선 간섭 잡음을 억제하고, 20~450Hz 4차 Butterworth 대역통과 필터를 적용하여 유효한 근전도 주파수 대역만 추출하였다.
  * 200ms 윈도우 크기와 100ms 증분을 적용해 신호를 분할한 뒤, 5종의 시간영역 특징을 추출하여 25차원의 특징 벡터를 구성하였다.
* **사용한 AI/ML 모델 :** 
  * SVM: RBF 커널 사용 (C=1.0, gamma='scale')
  * Random Forest (RF): 100개의 결정 트리 앙상블 구성
  * XGBoost (XGB): 400개의 트리, 최대 깊이 6, 학습률 0.05 설정
* **학습 및 테스트 방법 :** 
  * 데이터 누수 현상을 방지하기 위해 각 시행 내의 윈도우 특징들을 평균화하여 1,216개의 대표 샘플을 구축하였다.
  * 클래스 불균형을 방지하기 위해 층화 분할 방식으로 학습셋(969개)과 테스트셋(247개)을 구성하였습니다.
  * StandardScaler를 이용해 특징 스케일을 정규화한 후, Hold-out 평가와 5-Fold 교차검증을 병행하여 모델의 성능과 안정성을 모두 측정하였다.
  
### 실행 방법
```bash
python main.py
```

## 2. 모델 성능 비교
세 가지 머신러닝 모델의 Hold-out 지표, 교차검증 평균 정확도, 통계적 유의성 검정 및 계산 연산 비용을 비교한 결과다.

### ① 성능 비교표 (Hold-out 검증)
| Model | Accuracy | Precision | Recall | F1-score |
| :--- | :---: | :---: | :---: | :---: |
| SVM | 0.9028 | 0.9075 | 0.9028 | 0.9031 |
| Random Forest | 0.9190 | 0.9203 | 0.9188 | 0.9188 |
| XGBoost | 0.8866 | 0.8897 | 0.8864 | 0.8866 |

### ② 5-fold 교차검증 결과 (모델 안정성)
* SVM: 89.56 ± 1.89 %
* Random Forest: 92.60 ± 1.71 %
* XGBoost: 92.43 ± 1.58 %

### ③ 통계 검정 (대응표본 t-검정)
* SVM vs Random Forest: p = 0.1461 (유의하지 않음)
* SVM vs XGBoost: p = 0.1432 (유의하지 않음)
* Random Forest vs XGBoost: p = 0.5404 (유의하지 않음)

### ④ 계산 비용
| Model | 학습 시간(초) | 추론 시간 (ms/sample) |
| :--- | :---: | :---: |
| SVM | 0.131 | 1.621 |
| Random Forest | 0.441 | 60.103 |
| XGBoost | 7.557 | 6.402 |

### 성능 분석
Random Forest 모델이 Hold-out F1-score(0.9188) 및 5-fold 교차검증 평균 정확도(92.60%) 지표 모두에서 가장 우수한 분류 성능을 입증하였다. 이는 다수의 결정 트리를 결합하는 앙상블 기법이 생체 신호 고유의 분산을 효과적으로 억제하여 과적합을 방지했기 때문으로 판단된다. 반면, XGBoost는 순차적인 부스팅 구조 특성상 모델 학습에 7.5초 이상이 소요되어 계산 자원 대비 예측 효율성이 다소 부족했다. 대응표본 t-검정 결과, 세 모델 간의 성능 차이는 유의수준 0.05 하에서 통계적으로 유의하지 않은 것으로 확인되었다.

## 3. Confusion Matrix 분석
### Model 1 : Random Forest
![DenseNet161 혼동행렬](confusion_DenseNet161.png)

* 주요 오분류 유형: 동일한 손동작 내에서 팔꿈치 각도 조건만 상이한 클래스 간의 혼동 현상 (예: 주먹 쥐기 30°와 주먹 쥐기 60° 간의 오분류)

* 오분류가 발생한 이유에 대한 분석 : 주먹 쥐기나 손 펴기와 같이 특정 근육군의 뚜렷한 활성화가 동반되는 손동작에 비해, 단순히 팔꿈치 굴곡 각도만 유지하는 조건은 근활성 진폭의 차이가 상대적으로 미세하게 나타난다. 본 파이프라인에서 추출한 25차원의 특징 공간이 주로 신호의 진폭과 형태적 복잡도를 요약하는 시간영역 특징으로만 구성되어 있어, 이러한 미세한 각도 변동을 민감하게 판별하는 데 한계가 작용한 것으로 분석된다.
  
### Model 2 : SVM

* 주요 오분류 유형: 성능 지표상 타 모델과 유사한 경향을 보이며, 동일하게 팔꿈치 각도 변화에 따른 오분류가 주된 오차 요인으로 작용했을 것으로 추정다.

* 오분류가 발생한 이유에 대한 분석: 고차원 비선형 결정 경계를 생성하는 RBF 커널을 적용하였으나, 손동작 클래스와 비교할 때 각도 조건 간의 데이터 분포가 특징 공간 내에서 조밀하게 중첩되어 있어 마진을 충분히 확보하지 못한 것으로 판단된다.

### Model 3 : XGBoost

* 주요 오분류 유형: 상대적으로 낮은 정밀도와 재현율(각각 0.8897, 0.8864)을 기록하여, 특징이 모호한 클래스에서의 복합적인 오분류 빈도가 높았을 것으로 예상된다.

* 오분류가 발생한 이유에 대한 분석: 잔여 오차를 순차적으로 보정하는 알고리즘적 이점에도 불구하고, 제한된 시간영역 특징만으로는 정보 이득이 부족하여 설정된 최대 깊이 내에서 최적의 분기점을 형성하지 못한 것으로 보인다.

## 4. 최종 결과

* 가장 성능이 좋은 모델: Random Forest (교차검증 평균 92.60%)   

* 가장 성능이 낮은 모델: XGBoost (Hold-out 정확도 88.66%)

* 주요 오분류 클래스: 동종 손동작 내 서로 다른 각도 클래스 간 혼동

* 전체적인 실험 결과 및 느낀 점:
고비용의 딥러닝이나 추가 센서 없이, 5채널 sEMG 신호에 경량 머신러닝 모델을 적용하는 것만으로도 90% 이상의 다차원 동작 예측 정확도를 달성할 수 있음을 확인했다. 특히 Random Forest가 성능과 연산 비용의 훌륭한 절충안임을 알 수 있었다.   
다만, 교차검증 과정에서 시행 데이터를 무작위로 추출하여 섞었기 때문에, 동일 피험자의 신호가 학습과 테스트에 모두 포함되는 데이터 누수의 한계가 존재다. 향후 연구에서는 새로운 피험자에 대한 범용적인 인식률을 평가하기 위해 교차검증을 수행하고, 각도 판별 민감도를 높일 수 있는 주파수 영역 특징)을 추가해 보완할 필요성을 느꼈다.
